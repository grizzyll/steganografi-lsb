# Steganografi LSB — Data Security Web Platform

A Python-based web security platform implementing 
Least Significant Bit (LSB) steganography to hide and 
extract sensitive data — such as passwords — inside 
image files without visible alteration.

🌐 Live: (https://steganografi-lsb-kelompok4.streamlit.app/)

## Tech Stack
- **Backend**: Python
- **Frontend**: Web-based Interface
- **Deployment**: Vercel (Live)

## Features
- **Encode**: Hide sensitive data (passwords, messages) 
  inside image files using LSB steganography
- **Decode**: Extract hidden data from steganographic images
- **Suspicion Analysis**: Analyze images and calculate 
  percentage likelihood of containing hidden data

## Use Case
Secure password transmission via image files —

through standard encryption detection methods.
